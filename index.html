Comment se transmettre le suivi entre ingenieurs

1. A la fin de votre saisie, cliquez sur Exporter (JSON) : cela telecharge un fichier suivi_mileage_p3-366_[date].json.
2. Deposez ce fichier sur le dossier partage (Drive/Teams/USB) a la place du precedent.
3. Le prochain ingenieur ouvre cette meme page HTML et clique Importer (JSON) pour charger le fichier le plus recent avant de saisir sa session.
4. Le bouton Exporter Excel genere un instantane .xlsx lisible (pieces / sessions / changements) pour archivage ou impression.


Les donnees sont synchronisees automatiquement entre tous les appareils ouvrant ce meme artefact (toutes les 15s, ou via le bouton "Actualiser" en haut). Si l'artefact est ouvert hors de Claude, il repasse en mode local (navigateur uniquement). L'export JSON reste utile comme sauvegarde ponctuelle.
